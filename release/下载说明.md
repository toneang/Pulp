# Pulp 0.1.0

Windows 下载 `Pulp-0.1.0-windows-x64.exe`，双击即可运行；或解压同名 zip 后运行。无需安装应用本身，但需要系统安装 Microsoft Edge WebView2 Runtime。Windows 11 及多数 Windows 10 电脑已自带。缺少运行环境时请使用安装包，由安装程序引导安装 WebView2。

Mac 下载对应处理器的 `.app.zip`，解压后将 Pulp.app 放入“应用程序”。Apple 芯片选 apple-silicon；Intel 芯片选 intel。Mac 包需在 macOS 上构建，本目录不包含尚未构建的 Mac 应用。

应用未签名：Windows 可能显示 SmartScreen 提示；Mac 可能要求在系统设置“隐私与安全性”中允许打开。仅对自己构建或确认来源的文件放行。

笔记保存在系统应用数据目录，不在可执行文件旁；复制程序不会复制已有笔记。新建时的旧笔记保存在同一数据目录下的 archive 文件夹。

PDF 导出当前使用系统打印面板，Windows 选择 Microsoft Print to PDF。

## 生成 Mac 下载包

也可在装有 Node.js、pnpm、Rust 和 Xcode Command Line Tools 的 Mac 上，在项目目录运行 `bash package-macos.sh`，产物写入 `release/`。

将项目推送到 GitHub 后，在 Actions 中运行 Build Pulp packages。完成后从对应运行的 Artifacts 下载 Pulp-macos-apple-silicon 或 Pulp-macos-intel，其中包含 `.app.zip` 和 `.dmg`。此流程只生成构建附件，不自动发布公开下载页。
