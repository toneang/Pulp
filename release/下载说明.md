# Pulp 0.2.0 / Downloads

## Windows

推荐安装版 `Pulp_0.2.0_x64-setup.exe`：安装后可从 Windows「设置 → 应用」卸载。便携版 `Pulp-0.2.0-windows-x64.exe` 直接运行，或下载同名 zip 解压使用；没有卸载程序，退出后删除 exe 即可。需要 Microsoft Edge WebView2 Runtime。

Recommended: install `Pulp_0.2.0_x64-setup.exe` and uninstall through Windows Settings → Apps. The portable exe (also available as a zip) runs without installation. Quit and delete it to remove the program. WebView2 Runtime is required.

## macOS

Apple 芯片选 `Pulp-0.2.0-macos-apple-silicon.app.zip` 或对应 dmg；Intel 选 `Pulp-0.2.0-macos-intel.app.zip` 或对应 dmg。解压并将 Pulp.app 放入「应用程序」。仅在对应 macOS 构建成功后提供；缺失时请勿把源码压缩包当作应用。

Choose the apple-silicon or intel package for your Mac, unzip, and move Pulp.app to Applications. Mac assets are available only after native builds succeed. Source archives are not installable apps.

## 数据 / Data

升级前退出旧版，备份应用数据及自定义笔记文件夹。程序与数据分开保存，复制 exe 不会带走笔记。Windows 数据通常在 `%APPDATA%\com.yjw.pulp\`。新建前旧笔记自动归档，可从「历史」打开；这不是逐次编辑的版本备份。

Quit the previous version before upgrading. Back up app data and any custom notes folder. Copying the executable does not copy notes. History archives notes before creating or switching notes, not every edit.

设置中可选择中文 / English 及新笔记保存文件夹；新目录仅用于之后新建的独立 .md / .txt 文件。字号支持 A−/A+、Ctrl/Cmd+滚轮和加减号。PDF 导出目前使用系统打印面板。

Choose Chinese / English and a folder for new notes in Settings. Existing notes keep their original locations. Font size supports A−/A+, Ctrl/Cmd+wheel and plus/minus. PDF export uses the system print dialog.

应用未签名，系统可能提示安全警告；只运行确认来源的包。校验文件可用于核对下载完整性，不代表数字签名。

Builds are unsigned. Only run files from a trusted source. SHA-256 checksums help verify download integrity; they are not a digital signature.
