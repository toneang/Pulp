# Pulp v0.2.0

## 中文

让记录更顺手，也更容易找回。

- 新增中文 / English 界面切换，设置立即生效并持久保存；托盘菜单和应用内提示同步切换。
- 新增历史笔记入口：新建或打开历史前自动归档当前内容。
- 新增 A− / A+ 字号控制，支持 Ctrl/Cmd + 鼠标滚轮与加减号，记住字号选择。
- 新增自定义新笔记保存文件夹，之后新建的笔记以独立 .md / .txt 文件保存。
- 新增系统托盘入口，可打开、隐藏和退出 Pulp。
- 保留可编辑 Markdown 渲染、源码切换、表格尺寸选择、KaTeX 公式、置顶与 Markdown / PDF 导出。
- 重写中英文 README，增加下载、数据保存与发布说明。

### 升级须知

退出旧版 Pulp 后再安装或替换程序。升级前建议备份应用数据目录和自定义笔记文件夹。更改保存目录只影响之后新建的笔记，不会搬移旧文件。PDF 仍通过系统打印面板生成；应用目前未签名。Mac 包仅在对应平台构建成功后提供。

## English

A more comfortable place to write, with a way back to earlier notes.

- Switch between Chinese and English in Settings; preferences persist and tray menus update immediately.
- Revisit archived notes from History. Creating or opening another note archives the current one.
- Adjust and remember font size with A− / A+, Ctrl/Cmd + wheel, and plus/minus.
- Choose a folder for new notes, saved as individual .md / .txt files.
- Open, hide, or quit Pulp from the system tray.
- Continue writing in editable Markdown, switch to source, choose table sizes, edit KaTeX math, pin the window, and export Markdown or PDF.
- New bilingual product documentation and publishing instructions.

Quit the previous version before installing or replacing it. Back up app data and any custom notes folder before upgrading. Changing the notes folder applies only to new notes. PDF export uses the system print dialog. Builds are unsigned; Mac packages require successful native builds.
