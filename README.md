# Pulp

工具栏提供「新建」「导出 MD」「导出 PDF」。新建前会将旧笔记归档到应用数据目录的 `archive/`，新笔记使用设置中的默认格式。导出 MD 可选择保存位置；导出 PDF 打开系统打印面板，Windows 选择 Microsoft Print to PDF，macOS 选择“存储为 PDF”。打印仅包含笔记正文。

标题栏图钉按钮切换窗口置顶，按下状态表示位于其他窗口之上；启动时默认置顶。

轻量悬浮记事本。全局快捷键唤出，无边框、始终置顶，关闭即隐藏、进程常驻。

## 开发

```bash
pnpm install
pnpm tauri dev      # 开发模式（会自动起 Vite dev server）
pnpm tauri build    # 发布构建
```

> **注意**：单独跑 `cargo build` 产出的 debug 包会去连 `http://localhost:1420`，
> 必须同时开着 Vite dev server 才能显示界面，否则窗口里是「localhost 拒绝连接」。
> 要直接双击运行，请用 `pnpm tauri build` 的 release 产物，它把前端资源打进了 exe。

## 视图模式

Markdown 模式参照 Typora 的做法：整个画布只有一个视图，**默认就是渲染态**，
而且渲染态**可以直接打字编辑**（所见即所得），不是只读预览。

**左下角的按钮**在渲染态与源码态之间切换，按钮文字始终写着"点下去会到哪里"。
也可以用 `Ctrl+E`。

在渲染态里的改动会实时回写成 Markdown 源码（经 `turndown` 转换），所以两边
内容始终一致，切换与保存都不会丢字。粘贴会自动降成纯文本，避免把外部样式带进文档。

纯文本模式没有渲染一说，切换按钮自动隐藏。

## 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl/Cmd+Shift+P` | 全局显示 / 隐藏窗口（可在设置里改） |
| `Ctrl/Cmd+E` | 切换源码 / 渲染（仅 Markdown 模式） |
| `Ctrl/Cmd+S` | 立即保存 |
| `Ctrl/Cmd+,` | 打开 / 关闭设置 |
| `Esc` | 隐藏窗口（设置面板打开时先退回编辑） |
| `Tab` | 插入缩进；表格里跳下一格（末格再按补一行） |

### 格式化快捷键

两种编辑态通用，纯文本模式下自动失效。

| 按键 | 作用 |
|---|---|
| `Ctrl+B` / `Ctrl+I` | 加粗 / 斜体 |
| `Ctrl+Shift+D` | 删除线 |
| `Ctrl+K` | 插入链接 |
| `` Ctrl+` `` / `` Ctrl+Shift+` `` | 行内代码 / 代码块 |
| `Ctrl+1` … `Ctrl+6` | 一级 … 六级标题 |
| `Ctrl+0` | 回到正文 |
| `Ctrl+=` / `Ctrl+-` | 标题升一级 / 降一级 |
| `Ctrl+Shift+Q` | 引用（再按取消） |
| `Ctrl+Shift+U` / `Ctrl+Shift+O` | 无序 / 有序列表 |
| `Ctrl+Shift+T` | 插入表格（弹出尺寸选择器） |
| `Ctrl+M` / `Ctrl+Shift+M` | 行内公式 / 公式块 |
| `Ctrl+Shift+-` | 分割线 |

### 输入即转换

渲染态下照着 Markdown 习惯打字，敲完触发键就地变成真实结构：

| 输入 | 触发 | 结果 |
|---|---|---|
| `#` … `######` | 空格 | 各级标题 |
| `-` / `*` / `+` | 空格 | 无序列表 |
| `1.` / `1)` | 空格 | 有序列表 |
| `>` | 空格 | 引用 |
| ` ```js ` | 回车 | 代码块（带语言） |
| `$$` | 回车 | 公式块 |
| `$$x^2$$` | 闭合符 | 公式块（单行写法） |
| `---` | 回车 | 分割线 |
| `\| 列1 \| 列2 \|` | 回车 | 表格 |
| `**粗**` `*斜*` `` `码` `` `~~删~~` `$x^2$` | 闭合符 | 对应行内样式 |

配套手感：列表/引用里回车续行、空行再回车跳出；块首按退格把标题、引用、列表
降回普通段落；代码块里按 `Esc` 跳到下一段。

成对标记支持两种写法：**顺序打**（`$$x^2$$` 一路打到底，敲下闭合符即成形），
或者**先打标记再回填**（先打 `$$$$`，光标挪回中间慢慢写公式）。后者会在停手
约 0.6 秒后成形，中途打字不会被截断；按回车或切到源码态会立即结算。

公式用 KaTeX 渲染，**点一下公式**就能改 TeX，按 `Esc`/回车或点别处即重新渲染。

### 表格尺寸选择器

按 `Ctrl+Shift+T` 会弹出一张 8×8 的网格，像 Office 那样挑行列：

- **鼠标**：移动预览尺寸，点击确认
- **方向键**：上下调行数、左右调列数
- **回车**确认，**Esc** 取消

标注的「N 行」指内容行，表头另算。确认后光标落在第一个单元格，用 `Tab`
可以一格格往后跳，跳到末格再按会自动补一行。

### 自定义快捷键

设置面板里点击快捷键输入框，直接按下想要的组合即可。要求至少包含一个修饰键
（`Ctrl` / `Alt` / `Shift` / `Cmd`），录制中按 `Esc` 取消。

若新组合已被其它程序占用，注册会失败并**自动回滚到原快捷键**，不会让你失去唤出能力。

## 数据存放

笔记与设置分别存放在应用数据目录下的 `note.json` 和 `settings.json`：

- Windows：`%APPDATA%\com.yjw.pulp\`
- macOS：`~/Library/Application Support/com.yjw.pulp/`

输入停止 500ms 后自动落盘，隐藏/退出前也会强制保存。写入采用
「临时文件 + 原子替换」，避免写到一半中断损坏笔记。
